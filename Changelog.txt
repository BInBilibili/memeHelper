MemeHelper 更新日志
====================

2.7.1（2026-08-09）
--------------------
- 修复多图预览新增钩子造成的 React 重渲染异常，恢复所有图层正常显示。
- 模板工作台设置新增“主页模板显示大小”：小、中、大。
- 小尺寸约为原模板卡片的 0.5 倍，中尺寸约为 0.75 倍，大尺寸保持原有大小。
- 支持扫描 meme 目录中的多级非模板文件夹，并在工作台显示文件夹入口。
- 支持进入下一级目录、返回上一级目录以及点击路径中的任意目录跳转。
- 工作台顶部显示当前目录路径，例如 meme/、meme/ACGN/。
- 递归加载嵌套目录中的模板，保存和重命名时保留模板所在目录。
- 发行版版本目录增加本更新日志文件。

2.6.1
-----
- 可替换图层新增“多图排列”：无、横向排列、纵向排列、网格换行。
- 网格换行支持设置每行最多显示 1–12 张图片。
- 使用模板时，多张图片可在同一可替换图层内按设置排列。
- 绑定图层与颜色填充互斥，启用绑定图层后颜色填充控件置灰。
- 绑定图层会继承主可替换图层的多图来源。

2.5.3
-----
- 预览图片改为贴合可替换图层的下拉面板。
- 预览面板支持拖入图片、Ctrl+V 追加、删除图片和追加图片。
- 可替换图层重置会恢复图片、位置、尺寸、裁切和临时变换。
- GIF 时间轴支持拖入普通图层或 GIF 图层并插入帧。
- 多选帧时复制和删除操作对所有选中帧生效。
- 增加 Windows 应用名称、图标、窗口类名和产品元数据。

2.5.2
-----
- 多图预览窗口改为贴合左侧可替换图层的展开面板。
- 增加可替换图层单独重置功能。
- 群名单导入按钮改为“导入群名单（xlsx）”并移动到底部。
- 增加锁定照片宽高比说明。

2.5.1
-----
- 支持单可替换图层选择多张图片。
- 支持多张图片逐张生成作品或合成为 GIF。
- 增加群名单 XLSX 导入，并根据工号下载头像。
- 支持批量替换可替换图层和批量替换文字。
- 增加导出进度、取消导出和批量导出提示。

2.4.x
------
- 增加 GIF 图层、GIF 时间轴、帧播放时间、帧多选、帧复制、帧删除和帧排序。
- 支持将图层拖入 GIF 时间轴作为帧。
- 支持静态图层按指定 GIF 帧显示。
- 增加绑定可替换图层功能。
- 模板主页增加 GIF 标记和模板复制、打开模板文件夹等操作。
- 增加深色、浅色和跟随系统主题设置。

2.3.x
------
- 完成 Electron 到 Tauri 的迁移，支持断网运行。
- 模板与可引用图片保存到 exe 同目录的 meme 文件夹。
- 增加 config.json 全局配置。
- 增加撤销、重做、自动保存恢复、图层锁定、多选组合和照片裁切模式。
- 增加画笔、填充、橡皮擦、颜色选取器、选框和马赛克工具。
- 增加文字图层编辑、字体、字号、加粗、斜体、下划线、描边和文字锁定。
- 增加图层组展开收起、拖拽排序、合并、复制和多选。
- 增加混合模式、透明度、外边框、旋转吸附和锁定宽高比。
- 增加画布/图像尺寸切换、自动设置画布尺寸和视图缩放平移。
- 增加剪贴板复制、文件夹粘贴、拖拽替换照片和导出倍率。

早期版本
--------
- 支持创建、编辑、使用模板。
- 支持固定图层、可替换照片图层和文字图层。
- 支持生成图片并复制到系统剪贴板。
- 支持模板重命名、删除、收藏、搜索和排序。
