# MemeHelper

Windows 桌面表情包制作工具。你可以用现成模板快速生成图片或 GIF，也可以从零创建自己的模板。

## 下载与启动

1. 从 [GitHub Releases](https://github.com/BInBilibili/memeHelper/releases) 下载最新的 `MemeHelper-版本号-windows-x64.7z`。
2. 将压缩包完整解压到任意文件夹。
3. 双击 `MemeHelper.exe` 启动。

请不要直接在压缩包内运行程序，也不要只复制单独的 EXE 文件。模板和运行所需资源需要与程序一起保留。

## 模板工作台

打开程序后会进入模板工作台。这里可以：

- 浏览、搜索、收藏模板。
- 按普通模板或 GIF 模板筛选。
- 按最近使用、最近创建或名称排序。
- 使用文件夹整理模板；点击路径可以返回上级目录。
- 点击刷新，重新读取程序目录中的模板。
- 复制模板、编辑模板名称、打开模板文件夹或删除模板。
- 通过设置调整模板卡片显示大小；按住 `Ctrl` 滚动鼠标滚轮也可以快速调整。

将别人提供的模板文件夹放入程序目录下的 `meme` 文件夹，回到模板工作台点击刷新即可使用。模板文件夹应保持完整，不要只复制预览图。

## 创建和编辑模板

点击“新建模板”或模板菜单中的“编辑模板”进入编辑器。

### 图层

- **固定图层**：添加不会被替换的图片、背景或 GIF。
- **可替换照片**：添加矩形、圆形、圆角矩形或多边形照片区域。
- **文字图层**：在画布中点击位置后输入文字，可选择横排或竖排文本。
- 图层可以改名、锁定、隐藏、删除、复制、组合、取消组合和调整堆叠顺序。
- 支持 Ctrl 多选、Shift 范围选择，以及对齐和等距分布。
- 图层组可以展开或收起，组内图层仍可单独编辑。

### 属性调整

选中图层后，可以在右侧属性面板调整：

- 位置、宽高、旋转、水平翻转和垂直翻转。
- 透明度、图层混合模式和外边框。
- 照片适配方式、颜色填充、绑定图层和多图排列。
- 文字字体、字号、颜色、加粗、斜体、下划线、删除线、行距、对齐、背景、阴影和外描边。
- 多边形边数、顶点位置和圆角矩形的圆角半径。

所有图层都可以参与多选批量编辑。不同图层的属性不一致时，会显示“（多个值）”，控件默认显示第一个选中图层的值。

右侧属性面板和左侧图层面板都可以拖拽改变宽度，收窄后仍可通过拖拽恢复。

### 图片编辑工具

编辑器提供以下工具，并且只作用于当前选中的图层：

- 选择与移动
- 选框工具
- 快速选择工具
- 套索、多边形套索和磁性套索
- 画笔、填充和颜色选取器
- 橡皮擦（画笔擦除、擦除图层、魔法橡皮擦）
- 像素马赛克和高斯模糊

画笔、马赛克和橡皮擦可以调整大小；画布上会显示当前工具的范围预览。按住 `Alt` 可以临时使用颜色选取器。

### GIF 时间轴

添加 GIF 图层，或选择多张图片创建 GIF 图层后，编辑器会显示时间轴。你可以：

- 播放、暂停并跳转到指定帧。
- 调整单帧或全部帧的播放时间。
- 从外部拖入多张图片作为多帧。
- 拖拽调整帧顺序。
- 复制或删除单帧及多选帧。
- 将图层或 GIF 的帧拖入时间轴。

保存模板后，GIF 的帧数和播放时间会随模板一起保存。

### 撤销与保存

- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。
- `Delete` 快速删除选中的图层或时间轴帧。
- 编辑过程会自动保存恢复状态。
- 按 `Esc` 返回模板工作台；未保存时会出现保存、放弃或取消选项。

## 使用模板

点击模板卡片中的“使用模板”进入生成页面。

### 替换照片

- 左侧面板单击可替换照片区域，只会选中它。
- 双击区域选择图片；也可以直接把图片拖入区域。
- 支持一次选择多张图片。多图排列可设置为横向、纵向或网格换行。
- 点击预览图可以展开该区域的图片列表；可以追加、替换、删除、水平翻转或垂直翻转单张图片。
- 右键预览图可以对当前图片执行替换或删除，右键空白处不会弹出菜单。
- 如果模板有多个可替换区域，多张图片会按照图层顺序依次填入，超出的图片会被忽略。
- 绑定图层会跟随主照片变化，不会重复出现在替换列表中。

### 调整结果

在中间画布中可以拖动照片、调整大小和裁切位置。双击照片进入裁切模式，再次点击裁切按钮或切换工具可以退出。滚轮以光标所在位置为中心缩放画布，按住空白处拖动可以平移视图。

文字图层如果没有启用“禁用替换文本”，可以在使用模板时临时编辑。文字图层支持批次文本，可为 GIF 的每次播放或多图排列中的每张图片设置不同文字。

### 导出与复制

- “复制 N 张图片”会按当前照片数量生成静态图片并复制到系统剪贴板。
- “复制 GIF”会生成循环 GIF 并复制到系统剪贴板。
- 可以导出 PNG、JPEG 或 WebP。
- 导出倍率支持 `0.5` 倍及更高倍率，也可以直接输入数值。
- PNG 和 WebP 支持透明画布背景。
- 替换照片、移动、裁切等操作不会自动复制；只有点击复制按钮、使用复制快捷键或右键复制时才会写入剪贴板。

## 群名单导入

使用模板时，可以点击底部的“导入群名单（xlsx）”，选择符合表格格式的 Excel 文件。

导入流程可以：

- 按表格中的账号信息批量准备头像。
- 将头像依次填入一个或多个可替换照片区域。
- 在有文字图层时，选择是否用表格中的首行字段批量替换文字。
- 对单张图片、多个照片区域和 GIF 模板执行批量生成。
- 导入失败时显示失败名单，并使用备用方式继续完成文字替换流程。

头像来源可以在设置中选择，程序会自动完成后续处理，不需要手动填写路径或服务信息。

## 设置

模板工作台右上角的设置按钮可以调整：

- 主题：浅色、深色或跟随 Windows 系统。
- 模板主页显示大小：小、中、大。
- 群名单导入的头像来源模式。

设置会自动保存，重启程序后继续生效。

## 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |
| `Ctrl+C` | 复制当前结果、选区或选中的文字内容 |
| `Ctrl+V` | 粘贴图片或图层 |
| `Delete` | 删除选中的图层或 GIF 帧 |
| `Esc` | 退出当前编辑状态或返回上一级页面 |
| `Alt` | 使用画笔时临时切换颜色选取器 |
| `Shift` | 对齐、吸附或进行范围选择 |
| `Ctrl + 鼠标滚轮` | 调整模板主页卡片大小 |

## 离线使用

MemeHelper 的界面资源随应用一起安装，模板编辑和普通图片/GIF 生成功能不依赖网络。只有使用需要头像来源的批量导入功能时，才可能受到所选头像来源模式的影响。
